# Arquitetura MVC

O padrão MVC divide um sistema em três camadas com responsabilidades distintas: Model, View e Controller. Entender esse padrão é pré-requisito para trabalhar com qualquer framework moderno.

> Model busca. Controller organiza. View exibe.
